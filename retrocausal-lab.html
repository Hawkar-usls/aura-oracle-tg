Сценарий

Отредактируй JSON. Вероятности условные, вводятся человеком; пример демонстрационный и не основан на наблюдениях.

Обратный ход к настоящему

ДействиеP(исхода)*Ожид. полезностьРазница к базе

* Показывается вероятность первого исхода. Сравнение основано на заданных предположениях и не доказывает причинный эффект.

Что это доказывает?

Модуль может помогать принимать решения сейчас, но не передаёт сигналы из будущего. Физическая ретрокаузальность не установлена. Для научного прогноза нужен заранее опубликованный отпечаток прогноза и проверяемый независимый исход.

Локальная страница ничего не отправляет на сервер; для полноценной фиксации и последующего подсчёта Brier/log-loss используй протокол Python и Fortune Cookie. Скачанный JSON сам по себе не содержит доверенной временной метки.
